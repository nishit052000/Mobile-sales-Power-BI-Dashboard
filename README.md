Mobile Sales Dashboard – Power BI Project

Overview
This project is an interactive Power BI Dashboard built to analyze and visualize mobile sales data across different cities, brands, models, payment methods, and customer ratings. The dashboard provides meaningful business insights that help track sales performance, customer behavior, and transaction trends.

The dashboard is designed for:
Sales Analysis
Business Performance Monitoring
Customer Insights
Product Trend Analysis
Regional Sales Comparison

Key Features
1. KPI Cards

The dashboard displays important business metrics at the top:

Total Sales: 62M
Total Quantity Sold: 2K
Total Transactions: 322
Average Sales: 39K

These KPIs provide a quick overview of business performance.


2. Sales by City (Map Visualization)
Displays total sales distribution across different cities in India.
Helps identify high-performing regions and sales hotspots.
Cities included:
Delhi
Mumbai
Bangalore
Hyderabad

Patna
Ranchi

Madurai


3. Quantity Trend by Day
Line chart showing daily quantity sold.
Helps analyze sales fluctuations and peak sales periods.
Useful for identifying customer purchasing patterns.


4. Brand Performance Analysis

Table visualization showing:

Number of Transactions

6. Customer Ratings Analysis

Funnel chart displaying customer satisfaction ratings from 1 to 5.

9. Monthly Filter/Slicer

Interactive month-wise slicer allows users to:

Compare monthly sales performance
Perform time-based analysis
